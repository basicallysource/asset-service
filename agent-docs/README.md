# Agent Documentation

This directory holds public-safe, repository-wide guidance for agents and
external contributors.

- Add durable architecture decisions, operational conventions, and contributor
  workflows here as they become real.
- Keep documents accurate for a fresh contributor with no private context.
- Do not include credentials, personal information, deployment-specific details,
  customer information, or internal-only assumptions.
- Keep local scratch work and deployment notes outside this directory.

There is no implementation or committed architecture yet. Do not infer one from
this directory until it is documented explicitly.
